# 12 — Entrada e saída

O módulo `io` (exemplos 009, 029, 036):

```lum
use std::io;
use std::fs;

fn main() {
    // `println` escreve na tela. `io::read_line()` lê o teclado e
    // `fs::read_arquivo` lê um arquivo — ambos devolvem `Result`.
    println("lendo dados.txt...");
    match fs::read_arquivo("dados.txt") {
        Ok(txt) => println(txt),
        Err(e) => println(str::concat("erro: ", e)),
    }
    match io::read_line() {
        Ok(linha) => println("voce digitou: " + linha),
        Err(e) => println(str::concat("erro: ", e)),
    }
}
```

## Arquivos e logs

- `fs::read_arquivo(caminho)` / `fs::write_arquivo(caminho, texto)`
  devolvem `Result` (use `match` ou `?`).
- Para logs que crescem (`036_log.lum`), abra uma vez e reuse a mesma
  referência ("handle": o valor que representa o arquivo aberto).
- CSV: leia tudo, `str::split` por `"\n"` (linhas) e por `","` (colunas)
  (`029_csv.lum`).
